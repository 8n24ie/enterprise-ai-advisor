# FDE 项目顾问 · Enterprise AI Advisor

把工作里的模糊烦恼，整理成值得做、范围清楚、效果可验证的小项目。

面向业务负责人、开发者与 AI 服务团队，聚焦 FDE 的需求诊断、试点规划与验收判断。它不代替完整开发、部署或长期运营。

## 能帮你做什么

- 澄清实际流程和卡点，每轮优先询问两三个独立信息点。
- 比较 AI 辅助、普通自动化、先补基础、暂缓与证据不足。
- 设计小试点，明确人、AI、程序的职责及错误边界。
- 核算全流程人工投入，定义验收与停止条件。
- 诊断已有项目的使用、质量、成本和范围问题。
- 输出可交接的行动方案，保留事实来源、未知状态与累计投入。

## 安装与开始

下载本仓库，将 `skills/enterprise-ai-advisor` 整个文件夹复制到你的 Agent Skills 环境所使用的技能目录，再按宿主要求刷新或开启新会话。可先选择一个固定安装位置，避免重复安装同名技能。

在支持 `$技能名` 的环境中输入（其他宿主按其技能菜单或调用方式使用）：

```text
请使用 $enterprise-ai-advisor。我们公司找资料经常要问同事，
找到了又不知道是不是有效版本。我想改善，但不知道从哪里开始。
```

已有资料可直接附上流程、样本情况和投入限制；已有试点可提供预期、实际结果与累计投入，不必重新讲一遍全部背景。仅提供允许在当前环境使用的资料。

## 交付什么

《AI 小项目行动方案》：问题与流程、优先切入点、分工、第一版范围、数据条件、验收方法、未确认假设和下一步。条件不足时给出核实行动，不强行设计AI项目。

生成方案不自动授权开发、采购、发送消息或部署。没有执行结果不等于尚未启动，已启动项目沿用原期限、计数和投入上限。
